원카드

빨강·파랑·노랑·초록. 공격하고, 방패로 막고, 손을 비워라.

원카드 규칙

  • 같은 색 또는 같은 숫자면 낼 수 있습니다. (1~10)
  • ↺ 리버스 — 진행 방향 반전 (색별 1장)
  • ↠ 점프 — 다음 사람 건너뛰기 (색별 1장)
  • ✦ 체인지 — 원하는 색으로 변경, 언제든 가능 (4장)
  • 🛡 방패 — 공격을 무효화하고 턴 종료. 이후엔 아무 카드나 가능 (1장)
  • +1 / +2 / +3 — 공격. 방어 못하면 누적된 장수만큼 받음. 같거나 더 큰 공격/방패로 방어
  • 버린 패는 덱이 부족해지면 다시 섞어 사용합니다
  • 턴당 20초 — 시간 초과 시 카드 1장 받고 턴 종료
  • 1장 남으면 원카드! 버튼을 5초 안에 누르세요. 실패 시 +2장
  • 손패를 먼저 모두 낸 사람이 1등이며 즉시 종료. 나머지는 남은 카드가 적은 순으로 2~4등
